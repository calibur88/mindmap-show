# Mind Map Show（MMS）

Obsidian插件：把`.mms`结构化文本直接渲染为可交互思维导图——左栏管文件、中间画布看图、右栏看节点详情。

- **文本即数据源**：`.mms`是纯文本，用Markdown风格的`#`／`--`／`<=>`／`::`写节点，任何编辑器可改、Git可diff；
- **三栏工作区**：左栏挂Obsidian真实sidebar，中间是`.mms`专属FileView画布，右栏展示节点正文、注释、嵌入、引用链（节点的`<=>`＋`::`）、入链（含本文件来源）与出链（文件级）；
- **双视图渲染**：探索视图（DOM，可缩放拖拽）与全景视图（SVG，渲染内容静态全量、交互按需接入——SVG图元是一等DOM，节点点击选中与折叠徽标点击均已生效）共用同一套布局算法；
- **四方向布局**：`TB`上→下、`BT`下→上、`LR`左→右、`RL`右→左，由`mms_layout`逐文件指定；
- **三种连线**：`mms_line`取`line`（直线）、`curve`（带几何约束的三次贝塞尔曲线）或`elbow`（直角折线）；
- **跨文件引用**：`<=> 文件名.mms 节点文本`在第二遍扫描回填，支持前向引用，解析成功即画虚线并登记入链/出链；`:: 文件名.mms::节点文本`只做点对点定位、不建边；同名目标有多个时指向第一个并记`info`告警；
- **节点级指令**：`!-- key > value <-- 目标`给节点挂样式/行为扩展，仅支持规范§10.7清单内10个key（样式类`color`／`text-color`／`line-color`／`line-width`／`border-radius`／`background`／`opacity`＋行为类`collapsed`／`debug`／`locked`）；支持默认绑定上方最近节点、`<--`按「层级＋文本＋最近距离」寻址、前向引用与同key冲突保留先写者；样式类key渲染期沿祖先链就近继承（DOM/SVG双画法各有映射、两视图视觉一致——`color`均染文字、`background`均染底色，值校验防注入），行为类不传播；清单外key记`directive-unknown-key`告警且不存储；`collapsed`渲染折叠徽标（点击展开/收起直接写回文档指令行，持久化即文档）、`debug`画布叠加节点id调试层、`locked`禁点击选中（光标not-allowed、悬停提示）＋右栏置灰提示；
- **左栏文件搜索**：标签栏与文件树之间的搜索栏，在当前标签分组内按文件名过滤；「清空」只撤销关键词，回退到该分组的默认视图；
- **左栏折叠持久化**：文件夹折叠状态跨重启保持（存`data.json`），文件夹重命名/删除后路径自动迁移；搜索时临时忽略折叠，清空后恢复；
- **右栏交互跳转**：引用链／入链／出链条目单击高亮（互斥、再点取消），「跳转」按钮未高亮时跳目标节点、高亮后跳源码行（入链跳来源节点、出链高亮跳本文件`<=>`行）；
- **自动重扫**：`.mms`文件被编辑、重命名或删除后自动触发防抖全库刷新，无需手动点「刷新」；
- **导出图片**：左栏状态卡「导出图片」把当前脑图导出为标准SVG文件——点击后展开内嵌保存栏（默认路径`export/<源文件名>.svg`可改），走`vault`写入（覆盖需确认），桌面端与移动端体验一致；导出图基于全景渲染器、内联样式与`xmlns`声明，脱离Obsidian主题也能独立打开；
- **诊断闭环**：跳级、缺根、多根、目标缺失、同名合并等解析告警按`error`→`warning`→`info`排序，常驻左栏调试信息区。

## 安装

1. 准备产物三件套：`main.js`、`manifest.json`、`styles.css`；
2. 复制到vault的`<vault>/.obsidian/plugins/mindmap-show/`目录下；
3. Obsidian→设置→第三方插件→关闭安全模式→重新加载→启用Mind Map Show。

## 快速开始

```bash
npm install --registry=https://registry.npmmirror.com   # 装依赖，国内建议加镜像
npm run dev                                             # watch构建，产物直出 test-vault-local/.obsidian/plugins/mindmap-show/
node esbuild.config.mjs once                            # 单次构建，同样直出上述测试vault目录
npm run build                                           # tsc --noEmit + 产出 dist/
npx vitest run                                             # 跑 197 例 core/render 层单测
npx tsc --noEmit                                        # 严格模式类型检查
```

> `npm run build`只产出`dist/`，想让Obsidian里生效必须再跑一次`node esbuild.config.mjs once`或`npm run dev`。

## 核心功能

1. **文件面板（左栏）**：标签云按标签过滤、文件树按文件夹折叠（状态跨重启保持、重命名/删除自动迁移，箭头▸/▾指示）、调试信息区聚合全工程告警、状态卡放「手动刷新」「打开详情」「导出图片」三个按钮；
2. **画布（中间）**：两行工具栏（上行文件名＋标签区——超出3个标签折叠为「+N」可展开收起，防多标签溢出；下行节点搜索＋视图切换），搜索检索当前文件节点全部展示文本（名称／正文／注释／`<=>`与`::`引用／嵌入，精确名称命中优先），多个命中用「上一个／下一个」循环导航＋计数，命中后选中、居中视口并联动右栏；探索／全景一键切换，鼠标拖拽与滚轮缩放、触控单指平移与双指缩放共用同一视口控件，缩放范围0.1~8；
3. **节点详情（右栏）**：展示来源文件、节点正文、节点注释、嵌入资源、标签、引用链（该节点的`<=>`跨边＋`::`定位）、入链（`<=>`指向该节点的来源，同文件显示为「本文件」）、出链（文件级外部`<=>`聚合）；三卡条目可单击高亮（互斥），「跳转」按钮未高亮时跳目标节点、高亮后跳源码行；未选中节点时给出占位提示，文件移动后给出降级提示；
4. **刷新流水线**：全库扫描→解析→跨文件引用解析→出链聚合，一次刷新让三个视图同步；`.mms`文件变动后自动防抖触发；
5. **导出图片**：左栏「导出图片」→ 保存栏展开（默认路径`export/<源文件名>.svg`）→ 确认后经`vault.create`／`vault.modify`落盘（覆盖弹Modal确认）；三级探测当前文件（最近leaf的`FileView.file`→`getActiveFile()`→选中总线），不依赖视图实例；保存中禁用按钮防重复落盘，失败行内红字保持展开可改路径重试，成功`Notice`提示；
6. **设置（9项）**：默认视图、调试信息开关、3个线宽、4个间距；改动后400毫秒防抖自动落盘、重绘并重新扫描，无需手动刷新；
7. **入口与命令**：ribbon图标`git-fork`唤起文件面板，命令面板提供「打开文件面板」「打开详情面板」「刷新全部.mms」。

## .mms快速上手

最小可运行示例：

```mms
# 根节点
## 子节点A
正文属于紧邻的标题节点
** 注释：星号后至少一个空格
-- 子节点A的子节点
```

关键词速查：

| 写法 | 含义 |
|---|---|
| `mms_name`／`mms_tags`／`mms_layout`／`mms_line`／`mms_desc` | frontmatter五个固定键，控制显示名、标签、布局方向、连线样式、文件备注 |
| `mms_layout: TB｜BT｜LR｜RL` | 布局方向，一律以父→子的流向为准，缺省`LR` |
| `mms_line: line｜curve｜elbow` | 连线样式，直线／贝塞尔曲线／直角折线，缺省`line` |
| `# 标题` | 标题节点，`#`的个数决定层级，无H6上限 |
| `-- 子节点` | 挂到最近标题下的子节点 |
| 普通非空行 | 节点正文`content`，右栏展示，画布不渲染 |
| `** 注释` | 节点注释`annotation`，星号后至少一个空格 |
| `<=> 目标, 目标2	备注` | 跨边引用，跨文件写`文件.mms 节点`（空格分隔），备注前用Tab或两个以上空格 |
| `:: 节点` 或 `:: 文件.mms::节点` | 节点引用，点对点定位，不建边、不产生入链/出链 |
| `![[target]]` | 嵌入图片／脑图／文件／URL，按扩展名与协议分流 |
| `!-- key > value <-- 目标` | 节点级指令；无`<--`默认绑定上方最近节点，有`<--`按「#个数=层级＋文本精确匹配＋最近距离」寻址（支持前向引用）；目标写`## 文本` |
| `… <** 行尾注释` | 行内首个`<**`到行尾整段剥离，作用于标题行／指令行／正文行 |

完整语法见[.mms语言规范](docs/mms-语言规范.md)。

## 工程结构

```
mindmap-show/
├─ src/
│  ├─ main.ts              插件入口：装配适配器、注册视图与命令
│  ├─ host/                唯一类型出口 + Obsidian适配器
│  ├─ core/                解析、布局、索引等纯逻辑（可单测）
│  ├─ controller/          刷新流水线、全局索引、选中态总线
│  ├─ render/              探索（DOM）与全景（SVG）两种画法、SVG导出、视口
│  ├─ ui/                  左栏、右栏、状态卡
│  ├─ views/               FileView、ItemView、设置面板
│  ├─ settings/            设置schema与默认值
│  └─ utils/               DOM工具与键值构造
├─ demo/                   入库示例库（17个.mms分7目录，覆盖全部语法）
├─ docs/                   .mms语言规范
├─ test/                   单测目录（镜像src/结构，197例）
├─ styles.css              全部样式集中一处
├─ manifest.json           插件清单（版本1.7.0）
└─ test-vault-local/       本地测试vault（local后缀＝本地专用，不入库）
```
